# Test fixtures

Small synthetic files for manual testing. They are generated for this
repository and contain no customer data or third-party author metadata.

| File | Coverage |
|------|----------|
| `sample.csv` | Normal CSV with text, numeric, and empty cells |
| `multiline.csv` | Quoted multiline cells, commas, escaped quotes |
| `numeric.csv` | Numeric sorting, negatives, floats, scientific notation |
| `empty-cells.csv` | Empty and partially empty rows |
| `unicode.csv` | Accented, CJK, RTL, and emoji text |
| `semicolon.csv` | Semicolon-separated values with comma decimals |
| `sample.tsv` | Tab-separated values |
| `sample.xlsx` | Single-sheet workbook with numeric and empty cells |
| `multisheet.xlsx` | Three sheets, multiline cells, and formulas with cached values |
| `sample.xlsm` | Macro-enabled workbook with two sheets |
